# حكايات الجزيرة | Hikayat Al-Jazira

موقع عربي تجريبي بتصميم سينمائي مستوحى من إسطنبول، مبني بـ HTML وCSS وJavaScript خالص، دون أدوات بناء أو اعتماديات برمجية.

## محتويات المشروع
- `index.html` — هيكل الموقع وواجهة المستخدم العربية RTL.
- `styles.css` — التصميم المتجاوب والألوان والحركات.
- `app.js` — تصفية الحكايات والبحث والتفاصيل وقائمة المستخدم المحفوظة محلياً.
- `favicon.svg` — أيقونة الموقع.

## تشغيل محلي
افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً من مجلد المشروع.

## النشر على GitHub Pages
1. افتح تبويب **Settings** في المستودع.
2. انتقل إلى **Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
5. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

> الصور والخطوط تُحمّل من خدمات خارجية، لذلك تحتاج إلى اتصال بالإنترنت. النصوص والعناوين والحكايات الموجودة حالياً محتوى تجريبي وليست حلقات فيديو فعلية.
